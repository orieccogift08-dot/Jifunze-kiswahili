# Jifunze Kiswahili — Teaching + Payment Website

## Payment methods included
- M-PESA Paybill
- M-PESA Till Number
- Kenyan bank transfer
- International payment option
- WhatsApp payment-proof button

## Before publishing
Open `index.html` and replace:
- `YOUR_PAYBILL`
- `YOUR_TILL_NUMBER`
- `YOUR_BANK`
- `YOUR_ACCOUNT_NUMBER`
- `YOUR_INTERNATIONAL_PAYMENT_METHOD`
- `YOUR_INTERNATIONAL_ACCOUNT`
- `254XXXXXXXXX` with your WhatsApp number
- `KSh ___` with your actual lesson prices

Do not publish placeholder payment details.
